## ✨ Features

- **Luxury Product Showcase**: Ultra-premium renders of the iPhone 15 Pro Gold, MacBook Pro Gold, and AirPods Max Gold.
- **Dynamic Hero Sequence**: A smooth, interactive image sequence that responds to user movement.
- **Luxury Aesthetic**: Deep black backgrounds with gold-brushed accents, glassmorphism, and smooth parallax effects.
- **Hardware-Encrypted UI**: Simulated secure login experience with glowing gold particle animations.
- **Responsive Navigation**: Sophisticated desktop and mobile menus with elegant scroll-based transitions.
- **Interactive FAQ/Support**: Seamlessly integrated support and inquiry sections.

## 🛠️ Technology Stack

- **HTML5**: Semantic structure for better SEO and accessibility.
- **Vanilla CSS**: Custom design system using HSL colors and modern CSS properties.
- **JavaScript (ES6+)**: Core logic and custom interaction handling.
- **GSAP (GreenSock Animation Platform)**: Powering high-end scroll triggers and reveal animations.
- **Particles.js**: Custom background particle system for a premium feel.

## 📁 Project Structure

- `index.html`: The main luxury landing page.
- `style.css`: The design system and layout.
- `main.js`: Interaction engine and GSAP animations.
- `booking.html`: Exclusive reservation portal.
- `product_*.png`: High-fidelity luxury renders.
